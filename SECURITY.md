# Security

Report vulnerabilities privately through GitHub private vulnerability reporting: [open a report](https://github.com/aetelierxyz/aetelier-ledger/security/advisories/new), or use Report a vulnerability in the Security tab. You can also email support@aetelier.xyz.

Do not open public issues or pull requests for vulnerabilities.

There is no bug bounty.

Scope: the crates in `crates/` and the release binaries published on this repository. Reports apply to the latest release.
